# Exorium Network — Central de Regras

Site estático em português, pronto para GitHub Pages. Inclui logo e banner fornecidos, navegação por seis categorias, 37 artigos, busca global, links individuais, tabelas de punições e layout responsivo.

## Visualização
Abra `index.html` no navegador após extrair este pacote. Não exige instalação, compilação nem serviços externos. `regulamento.html` também permite leitura sem JavaScript.

## Publicação no GitHub Pages
1. Crie um repositório público `exorium-regras` na conta desejada.
2. Envie os arquivos deste diretório à raiz da branch `main`, incluindo as imagens WebP.
3. Em Settings > Pages, selecione Deploy from a branch, `main` e `/(root)`, e salve.
4. Aguarde o GitHub confirmar a publicação. Use o endereço efetivamente informado pelo GitHub Pages.

## Edição
- Regras e tabelas: `data.js`.
- Navegação e comportamento: `app.js`.
- Aparência e adaptação ao celular: `style.css`.
- Imagens: `banner.webp` e `logo.webp` (derivadas dos originais, sem alterações de composição).
- Ao alterar regras, atualize também `regulamento.html`, a versão de leitura sem JavaScript.

## Critérios editoriais
Conteúdo baseado no regulamento fornecido na conversa. A terceira reincidência após a primeira prisão é a quarta ocorrência punível com prisão na mesma categoria. Não foram inventados convites de Discord nem endereços de suporte. Durações não fixadas na proposta permanecem expressamente dependentes da administração; não foi adotada automaticamente a sugestão de histórico de 90 dias nem uma forma de contagem online/offline. Não há coleta de dados, analytics, cookies ou formulários de envio.
